# MonkyForce Frontend

Aplicación frontend Angular del monorepo MonkyForce.

## Ejecutar desde la raíz

```bash
npm run dev:frontend
```

También puede ejecutarse directamente:

```bash
cd frontend
npm start
```

La documentación canónica y las SPECs viven en la raíz del repositorio:

```text
../KNOWLEDGE.md
../ARCHITECTURE.md
../AGENTS.md
../ROADMAP.md
../spec/features/
```

La autorización efectiva pertenece al backend; los guards del frontend son UX/navegación.
